# CJWheelock.com

Static source for CJ Wheelock's personal website.

## Hosting

The `main` branch is published with GitHub Pages at `https://cjwheelock.github.io/`.
The production domain will be connected to this Pages site after its DNS records are migrated.

## Local preview

Run a static web server from this directory, for example:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173/`.
